Problem Statement

Duplicated Logic

Points logic in 3 systems (POS, e-commerce, mobile) — they disagree. 400 dispute tickets/month.

Slow Campaigns

Marketing cannot run promotions without a 3-4 week IT change request. Want 1-day turnaround.

No Self-Service

CS agents must phone IT to check a balance or fix a dispute. 10-30 min per case.

4 weeks campaign lead time 400 disputes/month No single liability report

Solution: PointHub Service

Centralized API
  • Earn points (base 25 THB = 1 pt + campaign multipliers)
  • Burn/redeem (1 pt = 0.25 THB, min 100, cap 50%)
  • Refunds with smart clawback
  • Campaign CRUD (activate in 1 day)
  • Manual adjustments with audit trail
  • Finance liability report
Key Features
  • Best-wins — no campaign stacking
  • Integer arithmetic — milli-points, no floating point
  • Idempotent — POS retry-safe
  • Deterministic — replay = same results
  • CS Screen — self-service for agents
  • Point Expiry — 12 months auto-expire

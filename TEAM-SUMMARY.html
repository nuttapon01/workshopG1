1. สิ่งที่เราสร้าง

PointHub คือบริการ loyalty points สำหรับ Siam MegaMart (120 สาขา, 800,000 สมาชิก) — รวมการคำนวณแต้มไว้ที่ API กลาง แทนที่ logic ที่กระจายอยู่ใน 3 ระบบเดิม

สิ่งที่ทำงานได้ตอนนี้: Earn/Burn/Refund API พร้อม campaign multiplier, Customer-Service UI (React + Ant Design), Point expiry job, Integration test replay ผ่าน expected-points.csv ครบทุก transaction

ใช้สำหรับ: POS terminals, CS agents (หน้าจอค้นหาสมาชิกและปรับแต้ม), Marketing (Campaign API), Finance (Liability report)
